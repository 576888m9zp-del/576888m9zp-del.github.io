プライバシーポリシー（fushigi-autopost）

制定日：2026年11月14日

1. このツールについて

fushigi-autopost は、運営者が自分で管理している YouTube チャンネルと Instagram アカウントに、自分で制作した動画を投稿するための個人用ツールです。運営者以外の利用者はいません。

2. 使う情報

  • 運営者のアカウントの認証情報（OAuth のトークン）：動画の投稿と、投稿結果の確認にだけ使います。
  • 投稿する動画・カバー画像・タイトル・説明文：運営者が用意したものです。

運営者以外の個人の情報は集めません。

3. 保管と第三者への提供

認証情報は、投稿処理を動かす環境の秘密の保管場所にだけ置きます。集めた情報を第三者に提供・販売することはありません。

4. YouTube API サービスの利用

このツールは YouTube API サービスを使います。YouTube の利用規約と、Google のプライバシーポリシーが適用されます。許可の取り消しは Google アカウントの権限のページから行えます。

5. 変更

内容を変えるときは、このページを更新します。
